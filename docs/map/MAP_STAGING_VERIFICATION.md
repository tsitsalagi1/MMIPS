# Map staging verification

Use synthetic, clearly labelled data only. After provider approval, verify exact provider/CSP origins; style, tile, sprite, glyph, source, image, and worker behavior; WebGL2 and context-loss fallback; map/list and filter parity; keyboard order; screen readers; reduced motion; and absence of geolocation, geocoding, routing, tracking, URL coordinate serialization, and private fields. Do not execute a database migration as part of renderer verification.
