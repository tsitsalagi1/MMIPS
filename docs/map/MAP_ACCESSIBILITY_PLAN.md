# Map accessibility plan

The complete linked list is authoritative and remains visible independently of the optional canvas. The experience provides a skip link, map-region label, plain keyboard instructions, visible loading/unavailable status, live result count, and polite React-rendered selection announcement without moving focus. Category and status remain textual and do not depend on color. Initial movement has zero duration and no pulsing or auto-fly is used. Keyboard, screen-reader, reduced-motion, and WCAG 2.2 AA browser verification remain release gates.
