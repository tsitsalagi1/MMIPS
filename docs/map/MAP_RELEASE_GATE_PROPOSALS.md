# Map release gates

Release requires `release-foundation-verify` on repository-pinned Node 22.23.1, provider/security approval, an exact-origin CSP, and supported-browser tests for MapLibre worker/resource behavior, WebGL2 fallback, map/list parity, keyboard use, reduced motion, and screen readers. The accessible list must remain complete. No geolocation, geocoding, routing, tracking, provider token, or broad CSP exception is permitted.
